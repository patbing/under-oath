    How it works

    The word is sealed

    The app, not a model, picks the word from a fixed list, and shows sha256(salt + ":" + word) before turn 1. At the end your browser recomputes it.

    Code judges the game

    The Asker must reply "Q: …" or "GUESS: …". Only a GUESS line can win, judged by plain string rules (case, articles, plurals, aliases). The Keeper's reply is cut to yes, no or unclear before the Asker sees it, so it can't leak the word.

    Every answer is re-asked

    A referee model gets the Keeper's prompt and that one question, no history. If they split yes/no, the Keeper's own model is asked again fresh. Two checks against the Keeper: flagged.
